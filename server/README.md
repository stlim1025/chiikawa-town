# 치이카와 마을 같이 놀기 서버

동물의 숲처럼 **내 마을 문을 열면 친구가 내 마을 코드로 놀러 오는** 작은 서버입니다.
콘솔 프로그램에서 ASP.NET Core 로 SignalR 허브(`/town`)를 띄웁니다.

- 게임 진행(돈, 가방, 자격증 …)은 지금처럼 **각자 기기에** 저장됩니다.
- 서버는 같은 마을 사람들의 **위치, 몸짓, 한마디**와 주인이 보내는 **마을 모습(시간, 마을 친구들, 풀)**을 나눠 주기만 합니다.
  저장하는 것이 없어서 DB 도 계정도 필요 없습니다.
- 한 마을에는 주인 포함 8명까지 들어올 수 있습니다(`appsettings.json` 의 `Town:MaxPlayers`).

## 게임에서 어떻게 노나요

마을폰 → **같이 놀기**

| 하는 사람 | 하는 일 |
|---|---|
| 주인 | **내 마을 코드**(처음 한 번 만들어져 저장되는 대문자 6자, 예: `K7QX2M`)를 친구에게 알려 주고 **마을 문 열기** 스위치를 켠다 |
| 친구 | 그 코드를 넣고 **놀러 가기** → 처음 마을에 올 때처럼 숲길 끝에서 정문으로 걸어 들어간다(리본에 '○○의 마을') |
| 친구 | 다 놀았으면 **집으로 돌아가기** → 떠나기 전 자리로 돌아온다 |
| 주인 | 스위치를 끄면(또는 창을 닫으면) → 와 있던 친구들은 저절로 집으로 돌아간다 |

주인 화면 왼쪽 위에는 **놀러 온 친구** 이름표가 뜬다(아무도 없으면 '마을 문이 열려 있어요').

놀러 간 친구는:

- 주인 마을의 시간(하늘, 시계), 마을 친구들(자리, 몸짓, 말풍선), 풀, 열매 덤불, 몬스터, 바닥 물건을 본다.
- 주인 마을의 **풀을 뽑고 열매를 따서 내 가방에** 넣는다. 주인 마을에서도 그 풀이 뽑히고 덤불이 빈다.
  누가 뽑고 있는 풀은 다른 사람이 건드릴 수 없다.
- 라멘 로우, 가구점, 포셰트 가게, 헌책방, 도구점, 맥주집에서 **내 돈으로** 산다(알바, 건배는 내 마을에서).
- **같이 토벌**: 마을 밖으로 나가 주인 마을 몬스터와 싸운다. 몬스터는 주인과 손님 중 가까운 사람을 노리고,
  맞으면 그 사람의 기운이 준다. 손님이 쓰러뜨리면 전리품, 토벌 점수, 토벌 일감은 손님 몫이다.
- **쓰러지면 깨워 주기**: 같이 노는 친구가 있으면 기운이 다 떨어져도 바로 기절하지 않고 그 자리에 쓰러져 30초 기다린다.
  친구가 다가가 '깨우기'를 누르면 기운 30으로 일어난다. 아무도 안 깨워 주거나 '그만 기다리기'를 누르면 원래처럼 기절한다
  (손님은 내 마을로 돌아가 기절, 시간이 흐르고 돈을 조금 잃는다).
- **바닥 물건 나눠 줍기**: 주인이 버린 물건을 손님이 줍고, 손님이 친구 마을에서 버린 물건은 주인 마을 바닥에 떨어져 주인이나 다른 손님이 줍는다.
- **주인 집 구경**: 주인 집 앞에서 '○○네 집 들어가기'. 주인 집 가구를 둘러보고, 집 안에 같이 있는 사람이 보인다(꾸미기, 침대, 옷장은 주인만).
- 친구 마을에서 얻은 것은 바로 내 저장에 들어간다. 놀러 간 채로 창을 닫아도 다음에는 떠나기 전 자리에서, 얻은 것을 가진 채 이어진다.
- 놀러 간 동안 내 시간과 퀘스트 이야기는 멈춘다.

주인이 집 안에 있어도 바깥에서 토벌 중인 손님이 있으면 몬스터는 계속 움직인다(주인은 노리지 않는다).

## 실행

.NET 10 SDK 가 필요합니다.

```bash
cd server/TownServer
dotnet run
```

`http://localhost:5280` 에서 열립니다. 브라우저로 열면 `chiikawa-town server: 0 players online` 이 보입니다.

### 혼자 시험하기(내 PC 안에서만)

게임은 고정 서버 주소(`src/net/multi.js` 의 `DEFAULT_SERVER`)로 붙는다. 내 PC 서버로 시험할 때만 주소 뒤에 `?mpserver=` 를 붙인다.

1. 게임을 `python -m http.server 8765` 로 띄운다(저장소 루트에서).
2. `http://localhost:8765/?mpserver=localhost:5280` 로 열고 마을폰 → **같이 놀기** → **마을 문 열기** 스위치를 켠다. 내 마을 코드를 본다.
3. 다른 창에서 `http://127.0.0.1:8765/?mpserver=localhost:5280` 로 열면 저장이 따로라서 다른 캐릭터로
   그 코드를 넣고 **놀러 가기** 해 볼 수 있다.

## 친구와 놀기: Tailscale Funnel

Tailscale Funnel 을 쓰면 **공유기 포트포워딩, 방화벽, 인증서 없이** 내 PC 의 서버를
고정 주소(`https://내PC이름.내tailnet이름.ts.net`)로 밖에서 들어올 수 있게 합니다.

1. Tailscale 을 설치하고 로그인한다.
2. Tailscale 관리 화면에서 **Funnel 을 켠다**(MagicDNS, HTTPS 인증서도 켜져 있어야 한다. 새 tailnet 은 기본으로 켜져 있다).
3. 서버를 켠 상태에서 아래 명령으로 5280 포트를 내보낸다(`--bg` 면 터미널을 닫거나 PC 를 다시 켜도 유지된다).

   ```bash
   tailscale funnel --bg 5280
   ```

4. `tailscale funnel status` 로 나온 주소(`https://….ts.net`)가 게임의 `DEFAULT_SERVER`(`src/net/multi.js`)와 같은지 확인한다.
   지금 주소: `desktop-jc07560.tail4a150e.ts.net`. 주소가 바뀌면 `DEFAULT_SERVER` 만 고치면 된다.
5. 친구는 GitHub Pages 의 게임에서 마을폰 → **같이 놀기** → **내 마을 코드만** 넣고 놀러 온다(서버 주소는 화면에 보이지 않는다).

> PC 가 켜져 있고 서버가 돌고 있을 때만 놀러 올 수 있습니다. 주인은 게임을 켜 둔 채로 있어야 마을 모습이 친구에게 갑니다.
> 서버 주소는 누구에게나 열려 있으니 마을 코드는 친구끼리만 나누세요. 안 쓸 때는 `tailscale funnel --https=443 off` 로 끌 수 있습니다.

## 설정(`appsettings.json`)

| 키 | 기본값 | 뜻 |
|---|---|---|
| `Urls` | `http://localhost:5280` | 서버가 듣는 주소 |
| `Town:MaxPlayers` | 8 | 마을 하나의 최대 인원(주인 포함) |
| `Town:MovesPerSecond` | 20 | 한 사람이 1초에 보낼 수 있는 위치 수(게임은 10번 보낸다) |
| `Town:MoveBurst` | 5 | 네트워크가 밀렸다 몰려와도 봐주는 개수 |
| `Town:ActsPerSecond` | 10 | 한 사람이 1초에 보낼 수 있는 행동 수(`Act`, `Direct` 같이) |
| `Town:ActBurst` | 30 | 행동이 잠깐 몰려와도 봐주는 개수 |
| `Town:AllowedOrigins` | `["*"]` | 접속을 허용할 게임 페이지 출처 |

## 통신 명세(SignalR 허브 `/town`, JSON)

게임은 협상(HTTP) 없이 바로 웹소켓으로 붙습니다(`skipNegotiation`). 한 메시지는 64KB 까지 받습니다.

### 클라이언트 → 서버

| 메서드 | 인자 | 설명 |
|---|---|---|
| `OpenGate` | `code: string`, `info: { name, look, x, z, yaw }` | 내 마을 문을 연다(주인). 돌려주는 값: `JoinResult`. 그 코드로 이미 열려 있으면 `taken` |
| `Visit` | `code: string`, `info: { name, look, x, z, yaw }` | 친구 마을에 놀러 간다(손님). 돌려주는 값: `JoinResult`. 문이 닫혀 있으면 `closed`, 꽉 찼으면 `full` |
| `Move` | `{ x, z, yaw, anim, area }` | 위치, 방향, 몸짓. `area`: `village`(마을과 바깥), `home`(주인 집 안, 집 안 자리), `away`(다른 장면). `anim: 'faint'` 는 쓰러져 깨워 주길 기다리는 중 |
| `World` | `{ c, d, n, m, s, r, w, b, g, h }` | 주인만: 마을 모습(아래). 서버는 내용을 해석하지 않고 손님들에게 그대로 보낸다(48KB 까지) |
| `Act` | `{ t, … }` | 손님만: 내 행동(아래)을 주인에게만 보낸다(512자까지, 너무 자주 오면 버린다) |
| `Direct` | `to: string`, `{ t, … }` | 같은 마을의 한 사람에게만(아래). 512자까지, 너무 자주 오면 버린다 |
| `Say` | `text: string`(30자까지) | 한마디(게임에서는 정해진 말만) |
| `Emote` | `name: string`(16자까지) | 몸짓 이름 |
| `Leave` | | 나온다. 주인이면 문이 닫힌다(연결이 끊겨도 저절로 나온다) |

`JoinResult`: `{ ok, reason, you, host, players: [{ id, name, look, move, host }] }`.
`reason`: `room`(코드가 이상함), `look`, `taken`, `closed`, `full`.

마을 코드: 서버는 한글, 영문, 숫자, `-` 로 1~16자를 받고 영문은 소문자로 바꾼다.
게임이 만드는 내 마을 코드는 헷갈리는 글자(I, L, O, 0, 1)를 뺀 대문자 6자다.

### 마을 모습(`World`, 주인 → 손님)

주인은 손님이 있을 때 0.2초마다(바깥에 나간 손님이 있으면 0.1초마다) 보낸다. 풀 · 덤불 · 바닥 물건 · 집 가구는 1초마다, 새 손님이 오거나 손님 행동이 있으면 바로.

| 키 | 모양 | 뜻 |
|---|---|---|
| `c` | `[day, t]` | 주인 마을 시계(날, 하루 중 0~1, 06:00 이 0) |
| `d` | `"YYYY-MM-DD"` | 주인의 시작 날짜(날짜 표시용) |
| `n` | `[[kind, x, z, yaw, mode, bubble, away]]` | 마을 친구들: 종류, 자리, 방향, 몸짓, 말풍선(없으면 `""`), 집 안이면 1 |
| `m` | `[[id, species, x, z, yaw, state, windK, atk, airY, under, hp, engaged, dormant, tele, tongue, stun, dead]]` | 바깥에 나간 손님 둘레의 몬스터(없으면 `[]`). `tele`: 공격 예고 표시(`['c', x, z, r, k]` 둥근 · `['l', x, z, yaw, len, w, k]` 띠, 없으면 0) |
| `s` | `[[x, z, vx, vz, r, color]]` | 날아가는 탄 |
| `r` | `[[x, z, r, k]]` | 포자 비 표시(차오름 k) |
| `w` | `[[id, kind, x, z, stage, hidden, flawed, busy]]` | 풀(마을 밖 포함): 주인 쪽 번호, 종류, 자리, 뽑힌 단계, 숨었으면 1(낮의 달빛 풀), 끊긴 적 있으면 1, 뽑는 중(0 아무도, 1 주인이나 마을 친구, 손님 연결 id) |
| `b` | `[[x, z, ready]]` | 열매 덤불(순서가 덤불 번호): 자리, 열매가 열렸으면 1 |
| `g` | `[[g, id, n, clean, weapon, x, z]]` | 바닥 물건: 번호, 물건, 개수, 깔끔한 수, 무기면 1, 자리 |
| `h` | `[[id, cx, cz, rot]]` | 주인 집 가구 배치 |

손님은 받은 값을 하나씩 확인해서 쓴다(모르는 풀 종류, 숫자가 아닌 자리는 버린다).

### 손님 행동(`Act`, 손님 → 주인)

주인은 받은 값을 하나씩 확인해 자기 마을에 반영하고, 바뀐 풀과 덤불은 다음 마을 모습으로 바로 모두에게 보낸다.
손님은 기다리지 않고 바로 자기 화면에 반영하고, 얻은 것은 자기 가방에 넣는다.

| 모양 | 뜻 |
|---|---|
| `{ t: 'grab', id }` | 그 풀을 뽑기 시작했다. 주인은 8초 동안 그 손님 몫으로 두고 주인과 마을 친구는 건드리지 않는다 |
| `{ t: 'drop', id }` | 뽑다가 그만뒀다 |
| `{ t: 'weed', id, stage, flawed }` | 여러 번에 나눠 뽑는 풀을 한 단계 뽑았다 |
| `{ t: 'weed', id, done }` | 다 뽑았다(`done`: `clean` 또는 `snapped`). 주인 마을에서도 뽑힌다 |
| `{ t: 'berry', i }` | 그 덤불의 열매를 땄다 |
| `{ t: 'hit', id, dmg, knock, x, z }` | 그 몬스터를 쳤다(주인이 피해를 주고, 쓰러뜨리면 `Direct` 로 `kill` 을 돌려준다) |
| `{ t: 'take', g, n }` | 바닥 물건을 줍겠다(아직 있으면 주인이 바닥에서 빼고 `Direct` 로 `got` 을 돌려준다) |
| `{ t: 'put', id, n, clean, weapon, x, z }` | 친구 마을에서 버렸다(주인 마을 바닥에 떨어진다) |

### 한 사람에게(`Direct`)

| 모양 | 보내는 사람 → 받는 사람 | 뜻 |
|---|---|---|
| `{ t: 'hurt', dmg, x, z, sp }` | 주인 → 손님 | 몬스터에게 맞았다(손님 기운이 준다) |
| `{ t: 'kill', sp, x, z, clean }` | 주인 → 손님 | 손님이 쓰러뜨렸다(전리품, 토벌 점수, 일감은 손님 몫) |
| `{ t: 'got', id, n, clean, weapon }` | 주인 → 손님 | 주운 물건을 건네준다 |
| `{ t: 'wake' }` | 누구나 → 쓰러진 사람 | 깨워 줬다(기운 30으로 일어난다) |

### 서버 → 클라이언트

| 이벤트 | 인자 |
|---|---|
| `playerJoined` | `{ id, name, look, move, host }` |
| `playerMoved` | `id`, `{ x, z, yaw, anim, area }` |
| `playerSaid` | `id`, `text` |
| `playerEmote` | `id`, `name` |
| `playerLeft` | `id`(손님이 나갔다) |
| `world` | 마을 모습(손님만 받는다) |
| `guestAct` | `id`, 손님 행동(주인만 받는다) |
| `direct` | `id`(보낸 사람), 한 사람에게 온 것 |
| `gateClosed` | 주인 이름(주인이 문을 닫았거나 연결이 끊겼다. 손님은 집으로 돌아간다) |

`src/world/weeds.js` 와 `src/world/berries.js` 의 `snapshot`, `showGuest`, `src/world/monsters.js` 의 `snapshot`, `fxSnapshot`, `playerHit`, `showGuest`, `guestStep`, `strikeGuest`,
`src/world/interior.js`(친구 집), `src/ui/intro.js`(걸어 들어가기).
